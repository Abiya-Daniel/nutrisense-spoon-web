# 📖 About

**NutriSense Spoon** is a modern nutrition tracking web application built using **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. It provides a clean, responsive, and user-friendly interface to help users explore nutrition-related information while demonstrating modern frontend development practices.

# ✨ Features

- 🥗 Smart Nutrition Tracking
- 📊 Interactive User Interface
- 📱 Fully Responsive Design
- ⚡ Fast Performance with Vite
- 🎨 Modern UI using Tailwind CSS
- 🔒 TypeScript Support
- 🌐 Cross-Platform Accessibility

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Abiya-Daniel/nutrisense-spoon-web.git
```

## Navigate to the Project

```bash
cd nutrisense-spoon-web
```

## Install Dependencies

```bash
npm install
```

## Start the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

# 📦 Build for Production

```bash
npm run build
```

---

# 👀 Preview Production Build

```bash
npm run preview
```
